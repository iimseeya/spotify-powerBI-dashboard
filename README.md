# Spotify Analytics Power BI Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** built to analyse Spotify music data and uncover insights into **track performance, artist popularity, and album characteristics**. Using Power Query, DAX, and interactive visualisations, the dashboard transforms raw Spotify data into meaningful business insights that support data-driven decision-making.

This project was created as part of my Business Analytics portfolio to demonstrate my ability to clean data, develop analytical dashboards, and communicate insights effectively through data visualisation.

---

## Business Objectives

The dashboard was designed to answer the following business questions:

### Track Analysis
- Which tracks achieve the highest popularity?
- How is track popularity distributed across the dataset?
- What proportion of tracks are explicit versus non-explicit?
- How has track popularity changed over time?

### Artist Analysis
- Does artist follower count correlate with popularity?
- Which artists contribute the largest share of tracks?
- Which genres have the highest artist representation?
- Which artists achieve the highest popularity?

### Album Analysis
- Which albums contain the largest number of tracks?
- How does popularity differ across album types?
- How have album releases evolved over time?

### 🎵 Track Analysis
Analyses Spotify tracks using KPIs, popularity distribution, explicit content analysis, and popularity trends over time.

**Key Insights**
- Track popularity is concentrated within the medium popularity range.
- Non-explicit tracks account for the majority of tracks in the dataset.
- Average track popularity has generally increased over time, despite year-to-year fluctuations.

---

### 👨‍🎤 Artist Analysis
Examines artist popularity, follower counts, genre distribution, and artist contributions through interactive visuals.

**Key Insights**
- Artists with larger follower counts generally achieve higher popularity, although follower count alone does not fully explain artist success.
- Artist popularity differs across genres, highlighting the diversity of successful artists within the Spotify catalogue.

---

### 🔍 Artist Details
Allows users to drill through to individual artist profiles, displaying:

- Top Tracks by Popularity
- Track Distribution by Album Type
- Artist KPIs
- Interactive filtering by release date, album type, explicit content, and genre

---

### 💿 Album Analysis
Explores album characteristics, release trends, popularity across album types, and albums with the largest number of tracks.

**Key Insights**
- Albums have higher average popularity than singles and compilations.
- The average album contains approximately 14 tracks.
- Music releases have become increasingly concentrated in recent years.
